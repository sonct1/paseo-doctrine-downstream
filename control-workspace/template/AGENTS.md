# Paseo Control Workspace

Đây là portfolio observation workspace, không phải project engineering repository hoặc control plane
thứ hai. Human giữ portfolio authority. Portfolio Supervisor chỉ quan sát exact project scope trong
`PORTFOLIO_SUPERVISOR_BINDING.md`, ghi causal learning vào one-writer `SUPERVISOR_NOTEBOOK.md` và
route finding về đúng project Lead/Human.

Không copy project source, project decisions, raw transcript, API key hoặc acceptance evidence vào
workspace này. Runtime IDs và current Lead phải resolve lại từ Paseo; `PROJECT_INDEX.yaml` chỉ là
routing metadata.
