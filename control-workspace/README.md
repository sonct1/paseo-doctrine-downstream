# Paseo Control Workspace template

Thư mục này là template experimental cho mutable Control Workspace Home. Foundation install mặc định
không dùng template; chỉ plan có explicit `--with-control-workspace` mới tạo một bản user-owned riêng.
Runtime không ghi ngược vào Git checkout hoặc `foundation/dist`.

Control Workspace giữ Portfolio Supervisor binding, Project Index, Supervisor Notebook, redacted
episode evidence và pending proposals. Nó không giữ project truth, engineering acceptance hoặc raw
credentials.
